# HR-Analytics-Dashboard-Power-BI
HR Analytics Dashboard - Power BI Overview  Built an interactive HR Analytics Dashboard using Power BI to analyze employee attrition, workforce demographics, overtime impact, and job satisfaction.
Dashboard Features
Total Employees
Attrition Count
Attrition Rate
Average Monthly Income
Average Years at Company
Attrition by Department
Attrition by Gender
Attrition by Job Role
Attrition by Overtime
Interactive Slicers
Tools Used
Power BI
DAX
Data Modeling
Interactive Visualizations
Key Insights
Attrition trends vary across departments and job roles.
Overtime significantly impacts employee retention.
Workforce analytics helps identify retention improvement areas.
Outcome

Developed a professional HR dashboard to support workforce planning and employee retention strategies.
